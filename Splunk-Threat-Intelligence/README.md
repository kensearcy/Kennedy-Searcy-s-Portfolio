# Splunk Threat Intelligence Lab

## Overview
This project demonstrates the use of Splunk to analyze and visualize
threat intelligence data. I imported multiple datasets, searched for
potential security indicators, correlated IP address data across
sources, and created a security monitoring dashboard.

## Skills Demonstrated
- Splunk
- SIEM fundamentals
- Threat intelligence analysis
- IOC analysis
- Data correlation
- Security dashboards and reporting

## What I Did
- Imported and configured datasets in Splunk.
- Used Splunk Search and Reporting to analyze threat intelligence data.
- Added additional data to identify activity associated with known
  TOR network IP addresses.
- Used a combined search across two data sources to identify IP
  addresses appearing in both.
- Created a "Threat Intelligence Monitoring" dashboard.
- Created a dashboard panel displaying known TOR IP addresses
  observed on the network.
- Configured the dashboard visualization and refresh settings.
- Converted the dashboard search into a Splunk report.
