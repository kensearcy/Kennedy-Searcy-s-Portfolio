# NIST RMF Security Assessment

## Overview
This academic project involved developing a cybersecurity governance
and compliance strategy for a simulated healthcare organization,
HealthSecure Global.

The project applied cybersecurity risk management concepts and NIST
frameworks to evaluate organizational risks, identify security gaps,
and recommend appropriate security controls.

## Skills Demonstrated
- NIST Risk Management Framework (RMF)
- NIST Cybersecurity Framework (CSF) 2.0
- NIST SP 800-53
- Cybersecurity risk assessment
- Security control mapping
- Gap analysis
- Governance, Risk, and Compliance (GRC)
- HIPAA security considerations

## What I Did
- Identified cybersecurity threats and vulnerabilities affecting a
  simulated healthcare organization.
- Performed qualitative risk analysis based on likelihood and impact.
- Categorized identified risks by severity.
- Mapped organizational risks and security requirements to NIST CSF
  2.0 and NIST SP 800-53.
- Selected Access Control (AC), Incident Response (IR), and Risk
  Assessment (RA) control families based on identified risks.
- Conducted a gap analysis of the organization's security posture.
- Recommended security improvements including role-based access
  control (RBAC), multi-factor authentication (MFA), and strengthened
  incident response processes.
