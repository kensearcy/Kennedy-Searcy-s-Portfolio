# Incident Response Investigation

## Overview
This project involved using Catalyst to document and investigate
a simulated cybersecurity incident involving a phishing email,
malicious attachment, and ransomware infection.

The investigation included documenting incident information,
analyzing an IP address using external threat intelligence
resources, and recording the findings within the incident case.

## Skills Demonstrated
- Incident response
- Incident documentation
- IOC investigation
- Threat intelligence research
- TTP identification
- Security case management
- Phishing and ransomware analysis

## Tools Used
- Catalyst
- VirusTotal
- AbuseIPDB

## What I Did
- Created and documented a simulated security incident in Catalyst.
- Worked with incident observables, tasks, and TTPs.
- Added an IP address as an incident artifact.
- Investigated the IP address using VirusTotal and AbuseIPDB.
- Reviewed threat intelligence findings associated with the IP.
- Documented the phishing and ransomware attack scenario.
- Recorded response recommendations and lessons learned.
- Closed the incident after completing the investigation and
  documentation.

## Incident Scenario
The simulated incident involved a phishing email sent to a user
containing a malicious attachment. Opening the attachment resulted
in ransomware executing on the affected system.

The complete incident response lab, investigation findings,
