cybersecurity, security operations, and defensive security. This portfolio
showcases hands-on academic projects I've completed while developing practical
skills in security monitoring, malware analysis, network security, incident
response, and governance, risk, and compliance (GRC).

## Cybersecurity Projects

[View Project](./Splunk-Threat-Intelligence/)

[View Project](./Malware-Analysis/)

[View Project](./NIST-RMF-Security-Assessment/)

VirusTotal, and AbuseIPDB while documenting observables, TTPs, and

[View Project](./Incident-Response-Investigation/)
